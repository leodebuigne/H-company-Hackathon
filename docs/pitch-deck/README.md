# Topil : pitch deck

Le diaporama du pitch final (11 diapositives, dans l'ordre imposé), tel qu'il était le 19 novembre 2026 au soir.

- **À regarder en ligne :** https://claude.ai/artifact/ATsZ6Zf7pMjkcq15bpcaLP
- **Dans ce dossier :** les sources du diaporama. `deck.json` donne l'ordre des diapositives, `deck.css` les styles, et `slides/` contient une page par diapositive, avec les notes de l'orateur dans la balise `<aside>`.

Ces fichiers sont une copie de sauvegarde : ils ne s'affichent pas seuls dans un navigateur, et les deux logos de la dernière diapositive ne sont stockés qu'en ligne. La version en ligne fait foi.
