Ce qui ne marche pas encore.

Les limites

Topil tourne sur un seul ordinateur, avec un seul compte. Il n’a pas encore été essayé par des personnes aveugles.

Ce que l’Agent API nous a appris

Garder la session ouverte entre deux étapes. Le navigateur cloud bute sur le CAPTCHA de connexion : nous passons par le Chrome local.

À améliorer

L’achat prend encore 60 à 90 secondes. Un lien direct et une mémoire pour chaque site, comme pour la SNCF.

La feuille de route

1 mois : essais avec vingt utilisateurs. 3 mois : dix sites. 6 mois : application mobile et premier marchand.
