Topil

4:35, 35 secondes. Suivre les flèches de gauche à droite. Point fort pour le jury H : l’agent travaille dans le navigateur de la personne, donc avec son compte déjà connecté. Choix d’architecture à assumer : l’agent est réservé à ce qu’aucun script ne sait faire (naviguer sur un site inconnu, remplir un panier, payer) ; la lecture d’une page de résultats connue est faite par le code, d’où les 20 secondes.
